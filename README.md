# VK Player

Windows 10/11 desktop-плеер на Tauri 2 + React с сохранённой библиотекой VK, очередью, плейлистами, фоновым воспроизведением и 15 темами. Tauri использует системный WebView2.

Версия 0.3.0 добавляет карточки артистов с релизами и действительными показателями
VK, подписки на новинки, ленту релизов, сниппеты с границами VK и редактор
плейлистов с проверкой облачного сохранения. На ползунке видны загруженные участки
аудио и состояние сети. Назад/вперёд работают боковыми кнопками мыши и Alt + стрелки.
Проверки и ограничения описаны в [отчёте 0.3.0](docs/release-0.3.0-verification.md).

## Запуск

```powershell
npm install
npm run dev
```

Для браузерного preview без Rust можно использовать `npm run dev:web`; Electron-команды оставлены только для миграционных тестов.

Production build:

```powershell
npm run build
npm run dist
```

Готовый Tauri-установщик после `npm run dist` копируется в `release-tauri/`. Артефакты Rust находятся в `%LOCALAPPDATA%/vk-player-build/target/`, чтобы избежать ошибок Windows при переименовании файлов в Documents.

## Вход и синхронизация VK

Основной способ подключения использует сессию официального окна VK Музыки. В настройках аккаунта нажмите «Подключить» или «Войти в VK Музыку» и войдите обычным способом на сайте VK. Регистрировать собственное приложение VK, вводить client ID, копировать cookies или токен не требуется. После входа Pulse автоматически запрашивает через клиент сайта все страницы «Моей музыки», плейлисты и состав каждого плейлиста. Имя, обложки, названия и порядок треков переносятся в интерфейс Pulse.

Пароль и авторизация остаются внутри профиля WebView2. Удалённое окно не получает разрешений Tauri. Rust запускает фиксированный адаптер сайта и принимает проверенные музыкальные данные; cookies, токены и прямые адреса аудиопотоков в React не передаются. Доступный вашему аккаунту поток воспроизводит отдельный HTMLAudio/HLS-плеер внутри скрытого WebView. Рекламная очередь сайта не запускается: нет вызова официального play и пропуска по таймеру. Источники и авторизация остаются внутри VK, а очередь, пауза, громкость и перемотка управляются из Pulse. Если VK не предоставляет доступный источник, появляется ошибка; переключения на рекламный плеер нет. Окно VK появляется, когда нужен вход, и автоматически скрывается после подтверждения аккаунта, не дожидаясь загрузки всей коллекции. Сохранённая сессия восстанавливается в фоне. Скрытый WebView остаётся работающим для музыки и синхронизации; при необходимости сайт можно открыть вручную.

На главной сортировка «Как в VK» сохраняет исходный порядок «Моей музыки», в том числе после повторной синхронизации и перезапуска. Дата локального импорта не меняет порядок треков VK. Локальные файлы идут после них, от новых к старым; каждый плейлист сохраняет собственную последовательность.

Библиотека появляется из сохранённого кэша сразу после запуска. В фоне плеер проверяет порядок и состав своей музыки, карточки плейлистов и обновляет изменившиеся данные. Недавно проверенный неизменившийся состав плейлистов используется повторно; полная проверка доступна кнопкой «Синхронизировать». Фоновая проверка выполняется каждые пять минут, а после сетевого сбоя повторяется с увеличением интервала до пяти минут. Плейлисты без надёжной версии повторно проверяются не реже десяти минут при доступном соединении. Первая установка этого обновления требует одной проверки для создания индекса. Подробности: [docs/cache-incremental-sync.md](docs/cache-incremental-sync.md).

Ошибка страницы, повтор страницы или изменение аккаунта не превращаются в успешную пустую коллекцию. Неудачная повторная синхронизация сохраняет предыдущую библиотеку; локальные файлы и локальные плейлисты хранятся отдельно. Недоступный по явному разрешению VK плейлист сохраняется как отдельная помеченная карточка. При восстановлении доступа следующее чтение вернёт его состав. Сессия сохраняется между запусками, пока VK её принимает; истечение или отзыв сессии потребует повторного входа.

Подключены чтение библиотеки и плейлистов, поиск по своей музыке и глобальному каталогу VK, воспроизведение, загрузка MP3, добавление найденного трека и удаление из своей музыки. Изменение подтверждается повторным чтением VK; локального исчезновения строки недостаточно для успеха. Редактирование плейлистов VK пока доступно в официальном окне. Недоступность отдельных треков, требования подписки и CAPTCHA не обходятся.

## Оформление и управление

В настройках есть отдельная вкладка «Темы»: базовые светлая, тёмная и контрастная, а также ретро, киберпанк, неон и другие варианты. Акцентный цвет, плотность, размер текста и анимация настраиваются отдельно. Полоса прокрутки следует выбранной теме. Треки без обложки получают устойчивую абстрактную композицию, которая сохраняется при сортировке.

Перемешивание и повтор находятся на нижней панели. Перемешивается вся доступная своя музыка; каждый трек проходит один раз за цикл. Очередь и её порядок сохраняются. Громкость раскрывается при наведении или фокусе клавиатуры. Нажатие исполнителя запускает поиск, а информация о треке показывает реальные сведения VK. Кнопка удаления видна в строке трека.

Адаптер опирается на текущий интерфейс сайта VK, который может меняться. На сохранённом реальном аккаунте подтверждены импорт библиотеки и78 плейлистов, сохранение порядка, восстановление входа и независимое воспроизведение доступного аудио. Один сохранённый плейлист сам VK не разрешил загрузить: его название и обложка остаются видимыми с пометкой недоступности. Ошибки не превращаются в пустой успешный импорт. Независимые нативные проверки подтверждают ноль вызовов официального рекламного play, паузу, смену трека и синхронизацию во время загрузки источника. Технические источники и границы проверки описаны в [docs/vk-access-evidence.md](docs/vk-access-evidence.md).

## Добавление MP3 и ссылок

На главной «Добавить в VK» и в разделе «Загрузить в VK» выберите MP3. Он передаётся в официальный загрузчик VK без перекодирования на компьютере; название и исполнитель берутся из ID3, затем из имени «Исполнитель - Название». Сообщение «В VK» появляется только после сохранения и отдельного чтения библиотеки. Запускается новая синхронизация, поэтому новая запись появляется сверху в порядке VK. Для прежних локальных треков есть меню «…» → «Загрузить в VK». Локальная копия при этом остаётся.

В поле «Ссылка на трек» принимаются прямые HTTPS-ссылки на аудиофайл, страницы SoundCloud с разрешённым автором скачиванием оригинала и отдельные видео YouTube. По умолчанию добавление идёт в VK и плеер. Для VK нужен MP3; оригинал SoundCloud другого формата можно сохранить локально. Прямые файлы и оригиналы сохраняются без дополнительного кодирования. YouTube для VK преобразуется в MP3 320 кбит/с: сжатый исходник нельзя преобразовать полностью без потерь. При выборе «Только локально» используется лучшая доступная дорожка без перекодирования.

Для YouTube можно включить системный VPN или указать свой зарубежный прокси в «Подключение к YouTube». Встроенного зарубежного сервера нет. На машине разработки реальная загрузка YouTube и воспроизведение прошли без прокси. SoundCloud может быть недоступен на текущем сетевом маршруте; приложение сообщает об этом. Авторские ограничения на оригинал не заменяются низкокачественным stream.

Загрузка обрабатывает до20 MP3 за раз, до200МБ каждый. Для каждого файла есть результат: сохранён, ошибка, пропущен или требуется проверка. При потере ответа после сохранения повторная отправка не запускается автоматически. По URL действуют ограничения размера/времени и проверка сетевых адресов. Смена аккаунта отменяет оставшуюся партию.

Компоненты yt-dlp, FFmpeg/FFprobe и Deno включаются в установщик из официальных дистрибутивов с проверкой закреплённых SHA-256 (`npm run prepare:imports`). Они запускаются только при импорте по ссылке и не занимают память в простое. Источники и лицензии: `src-tauri/resources/import-tools/SOURCES.txt`.

### Если вход был выполнен в предыдущей сборке

1. Завершите предыдущий Pulse полностью. Если включено сворачивание в трей, выберите «Выйти» в меню значка Pulse рядом с часами: один крестик может оставить старый процесс запущенным.
2. Установите обновлённую сборку из `release-tauri/` и запустите Pulse заново. Существующий профиль официального окна сохраняется; при запуске приложение пытается восстановить подключение.
3. Откройте «Настройки» → «Аккаунт VK» → «Войти в VK Музыку». Если VK уже помнит вход, повторная авторизация не нужна. Откройте раздел «Музыка», если после входа сайт остался на другой странице.
4. Нажмите «Синхронизировать» для нового чтения, в том числе после ошибки при сохранённом аккаунте. Дождитесь сообщения с числом треков и плейлистов. При проблеме показывается ошибка, а предыдущая библиотека сохраняется.

## Проверки

- `npm run typecheck` — TypeScript без ошибок.
- `npm run build` — production renderer.
- `npm test` — unit-проверки `pulse-media` range parser.
- `node --test qa/*.node.mjs` — storage recovery, VK ID PKCE/refresh и проверки session bridge.
- `node --test qa/vk-web-adapter.node.mjs qa/vk-web-independent.node.mjs` — чтение страниц сайта, смена аккаунта, повреждённые ответы и команды независимого транспорта на контролируемом runtime. Реальный VK эти тесты не открывают.
- `node qa/browser-adversarial.mjs` — adversarial renderer suite.
- `node qa/playback-edge.mjs` — 9 adversarial-сценариев для ошибок, буферизации, repeat и быстрых переключений.
- `node qa/vk-session-adversarial.mjs` и `node qa/vk-mutation-adversarial.mjs` — независимые сценарии VK на контролируемых ответах: выход, неполная синхронизация, поиск и неподтверждённые изменения. Эти тесты не доказывают доступ к реальному VK.
- `node qa/tauri-integration.mjs` — нативный Tauri smoke test с реальным WAV после debug-сборки.
- `node qa/vk-order-independent.mjs` — независимые проверки порядка VK при обновлении, перезапуске и воспроизведении следующего трека.
- `node qa/tauri-vk-web.mjs` — вход, скрытие окна VK и фоновое воспроизведение на изолированной тестовой сессии.
- `node qa/tauri-vk-upload.mjs` — пять изолированных нативных сценариев: исходные MP3-байты, частичные ошибки и неопределённое подтверждение, а также названия при неполных ID3-тегах. Реальный аккаунт не изменяется.
- `node qa/installed-final-readonly.mjs` — повторная сверка всей библиотеки, метаданных и состава плейлистов с установленным плеером, временно запущенным с диагностическим портом9226. Скрипт ничего не загружает в аккаунт.
- `cargo fmt --manifest-path src-tauri/Cargo.toml -- --check` и `npm run test:rust` — Rust backend и VK ID OAuth tests.

## Замер памяти

До подключения session bridge на машине разработки, Windows/WebView2 155, пустая библиотека, release-сборки и 20 секунд простоя: всё дерево Tauri — 380,5 MiB working set / 199,3 MiB private bytes; Electron — 642,3 / 528,6 MiB. Working set включает общие страницы, поэтому это не точный объём уникальной физической RAM. Этот замер не включает постоянно работающее окно VK: для текущего режима нужен новый замер. Результат зависит от ОС, WebView2 и библиотеки. Воспроизводимый сценарий: `qa/memory-benchmark.ps1`; прежние данные: `qa/memory-baseline.json`.

Отдельный транспорт Pulse не запускает рекламную очередь сайта и не подмешивает рекомендации. Доступ к источникам зависит от аккаунта и текущего интерфейса VK. Любые рекламные фрагменты, встроенные непосредственно в само аудиосодержимое, от трека автоматически не отделяются.
