# Pulse 0.5.0-preview.7 — коллекции, артисты и миксы

Предварительная сборка следующего обновления. Опубликованный preview.6 и
стабильный канал обновлений не заменяются. Общие функции остаются в `src/` и
`src-tauri/`; идентификатор `ru.vkplayer.desktop` и профиль сохранены.

## Изменения

- Перенос метаданных любимых треков и плейлистов Spotify / Яндекс Музыки,
  CSV/TSV/JSON, исходный порядок, повторные записи и отчёт по совпадениям.
  Незавершённый поиск продолжается; неполная выдача не затирает полный список.
- Отдельное подтверждённое сохранение найденного в VK: повторная операция
  обновляет связанный плейлист, локальные ссылки переходят на собственные ID.
  Повторы остаются в исходном локальном списке; VK принимает уникальные ID.
- В «Моей музыке» доступны порядки импорта Spotify и Яндекс Музыки. Порядок
  «Как в VK» остаётся исходным порядком VK.
- В карточке артиста есть отдельный полный каталог с постраничной загрузкой.
  Последующие поиски не вытесняют уже показанные или закреплённые записи.
- В разделе «Миксы» отдельно доступны рекомендации VK и локальный Pulse Mix.
  Последний использует историю выбранных песен, разнообразие исполнителей и
  ограниченную долю новых записей, когда своей музыки достаточно. Он не
  позиционируется как нейросетевая модель или официальный поток VK Mix.
- Удалён альбомный стиль; старые настройки мигрируют в минимальный.
  Добавлены Y2K / 90-е и «Стекло» — полупрозрачные поверхности внутри окна.
- Кнопка динамика включает mute с восстановлением громкости; перемотка
  увеличивается при взаимодействии без прямоугольной рамки. Клавиатурный
  фокус обозначается на круглом бегунке.

## Авторизация и реальные ограничения

Яндекс: отдельное постоянное официальное окно, чтение метаданных авторизованной
страницы без извлечения паролей, cookies, токенов или заголовков. Проверены
актуальные интерфейсы публичной страницы и отсутствие ложного входа в гостевом
профиле. Личная авторизованная коллекция пока не проверена пользователем.
Это адаптер сайта, а не обещание неизменного публичного API Яндекса.

Spotify: PKCE с системным браузером, проверенным loopback callback и токенами
в системном хранилище. Технические ключи не запрашиваются у слушателя.
Владелец Pulse должен настроить публичный Client ID при сборке и получить
допуск Spotify. В этой сборке ID отсутствует, поэтому личный Spotify-вход
недоступен. Вход, refresh и отзыв согласия реальным аккаунтом не проверены.
Ограничения Spotify 2026 и актуальные `/items` / `item` описаны в
[инструкции импорта](collection-imports.md). Публичный Spotify embed в текущем
регионе вернул 451; это отказ, а не пустой успешный импорт.

Аудио Spotify / Яндекса не извлекается из защищённых потоков. Список переносит
метаданные, а разрешённая воспроизводимая запись ищется существующим механизмом
Pulse. Точное совпадение должно быть единственным; неоднозначные версии
пользователь выбирает сам. Сетевой отказ не объявляется отсутствием песни.

Предел хранения отчётов: 100 коллекций / 50 000 записей суммарно, до 20 000
в одном списке. Новый импорт сверх предела отклоняется до изменения прежних
данных. Повреждение или обрезка при восстановлении обозначаются как частичные.
Сохранение одного плейлиста в VK ограничено 5000 уникальными найденными записями.

## Выполненные проверки

- TypeScript и production frontend build: успешно.
- Vitest: 197/197; Node adapter regression suite: 315/315.
- Rust: 196/196, 6 явно пропущенных внешних/codec проверок. Публичная сетевая
  проверка Яндекса была отдельно выполнена: 100 из 100 записей, HTTP 200.
- Независимый чистый Edge: 21 сценарий импорта/миксов, 4 сохранения в VK с
  синтетическим провайдером, 8 каталога артиста, 17 тем и HUD.
- Реальный отдельный Windows WebView2 `VK Player QA`: 10/10. Два WAV через
  Rust; CSV B/A/B; подбор, сортировка, повторы, сохранение на диск и повторный
  запуск; mute; продвижение аудио и перемотка 1.0 → 11.3 с; отсутствие рамки;
  удаление неизвестных credential/audio полей. Spotify status был заменён
  заглушкой до показа импорта, keyring не изменялся.
- 20 000 записей / 2000 собственных записей в чистом Edge: около 3.8 с без
  сетевых запросов, 4 снимка прогресса, heap около 26 МБ, максимальный разрыв
  heartbeat около 41 мс. Это замер синтетического сопоставления, не полного
  приложения и не скорости импорта через интернет.
- Визуальные проверки полного интерфейса 1440 и 960 пикселей: нет горизонтального
  переполнения и ошибок renderer; кнопки микса остаются внутри toolbar.
- Независимые существующие проверки воспроизведения: 31/31 и 41/41, без изменения
  аудиотранспорта этого обновления. Прослушивание всей библиотеки и отсутствие
  слышимых микропрерываний на любых устройствах не утверждаются.

Пользовательский установленный плеер не завершался, профиль и сессия не
очищались/не копировались. QA использует отдельный identifier и временные данные.

## Платформы

Windows 10/11: проверки выше выполнены на Windows 11. Установка поверх личного
профиля автоматически не выполнялась. Для проверки macOS требуется CI-сборка
обоих таргетов из той же ревизии; результат сборки фиксируется отдельно.
Физический Mac для проверки входа, keychain, импорта, аудио и обновления
недоступен. macOS остаётся неподписанным preview, Android не реализован.
