# Pulse 0.5.0-preview.6 — сопоставление записей и независимые источники

Проверка предварительной версии перед публикацией в GitHub по запросу пользователя.
Windows и macOS пакеты публикуются в отдельном prerelease с одинаковой версией
и из одной ревизии; стабильная ветка обновлений не переключается на preview.
Профиль пользователя не очищался, установленный плеер не завершался и новая
версия поверх него автоматически не устанавливалась.

## Причины и изменения

Два сообщённых отказа воспроизведены на настоящих ответах SoundCloud:
«все сложно» — nuisance и «МальчикТемныйНачальник» — касари@_~.
Поиск работал, но дополнительные кредиты и оформление названия мешали
автоматическому сопоставлению. Найденные записи отличаются от длительности VK
на 0,404 и 0,149 секунды соответственно.

- Распознаются явные кредиты `prod.`, `p.`, `прод.`, компактные списки
  нескольких продюсеров, декоративное каомодзи и отдельная пометка `неФорс`.
  Свободный неизвестный подзаголовок не удаляется для автоматического выбора.
- Запись участника через `+имя` учитывается, только если другой источник
  независимо перечисляет полный соответствующий набор исполнителей.
  Пометка `[все площадки]` распознаётся как оформление.
- Названия только из emoji не становятся пустыми. Последовательность,
  количество, тон кожи, флаги и состав символов через ZWJ сохраняют значение.
- Проверки исполнителя, версии, длительности, цензурной редакции, ISRC и
  доступности SoundCloud продолжают выполняться. Совпадение метаданных —
  предложение источника, а не результат сравнения аудиоотпечатков.
  Неподписанные компактные списки имён остаются ограниченной эвристикой:
  неизвестное обозначение версии может быть нераспознаваемым. Известные
  преобразования звука, версии, редакции и номера частей блокируют автоочистку.
- Недоступность записи в VK больше не запрещает независимый поиск и
  воспроизведение разрешённой записи SoundCloud. Статус `available` в VK
  не переписывается. Плейбек, очередь, следующий трек и shuffle используют
  одинаковое правило; отсутствующие локальные файлы не включаются.
- При отказе SoundCloud ограниченная VK-запись не запускает снова заведомо
  недоступный VK. Ошибка содержит действие для выбора источника. Актуальное
  ограничение после обновления метаданных учитывается и в обработчике ошибок.
  Проверки активного аккаунта, регистрации записи и доступа провайдера сохранены.
- В повторном живом прогоне зафиксирован единичный отказ запуска после
  успешного выбора той же записи; отдельный повторный запуск сработал.
  Добавлена одна автоматическая повторная попытка SoundCloud для той же записи
  и позиции до резервного VK или явной ошибки. Дедлайн продвижения 6 секунд
  сохранён. Повтор не означает получение нового upstream grant: разрешённый
  кеш провайдера может использоваться снова. Две неудачи не запускают цикл,
  а 30 секунд устойчивого продвижения восстанавливают бюджет на поздний сбой.

В приложение не добавляется фоновый обход всей библиотеки. Массовый аудит
выполнялся отдельно, последовательно и с ограничением частоты запросов.

## Объём аудита библиотеки

Проверены первые **800 собственных записей** в сохранённом порядке VK.
По `addedAt` список не пересортировывался: это время синхронизации.
Снимок библиотеки датирован **21 октября 2026, 21:09 по Самаре**; он может
отставать от текущего состояния аккаунта. В нём 4693 собственные записи,
всего с результатами поиска и другими источниками — 20098.

После исправления правил 223 записи имеют приоритет SoundCloud, 577 сохраняют
приоритет VK. Выполнена проверка метаданных, сохранённых привязок и ограниченный
поиск SoundCloud. Сеть VK и полное воспроизведение всех 800 записей не проверены.
Пустые и неоднозначные результаты поиска не объявляются отказами аудио.

Пять записей имеют `available=false` именно со стороны VK. Для двух найдены
единственные подходящие предложения SoundCloud; для двух найдены несколько
подходящих записей; для одной точного предложения среди результатов нет.
Это проверка метаданных, а не подтверждение звучания всех пяти записей.

Из 207 записей, для которых выполнялся поиск, **99** имеют единственное
наблюдавшееся точное предложение, **19** требуют проверки, **15** имеют несколько
точных предложений и **74** не имеют точного предложения среди результатов.
Для остальных 16 записей с приоритетом SoundCloud использованы уже сохранённые
привязки без сетевого поиска. Эти 16 не добавлены к 99 результатам нового поиска.
Для всех 207 сохранены полные наблюдавшиеся пулы, первые 50 перепроверены.
Это первые страницы до трёх запросов, а не исчерпывающий обход каталога.

514 запросов метаданных: 513 HTTP 200 и один HTTP 504, успешно повторённый позже.
Получено 12366283 байта метаданных, аудио в массовом аудите не скачивалось.
Файл библиотеки не изменился. Привязки пользователя могли меняться параллельно
его работе, аудит их не записывал. Локальные отчёты исключены из Git:
`qa/library-source-audit-results.json` и `qa/library-source-rerank-results.json`.
Они содержат метаданные библиотеки и не включаются в установщик.

## Проверки

- Production frontend build и TypeScript: успешно.
- Финальный Vitest: **184/184**.
- Node-регрессии: **303/303**.
- Rust: **172 успешно, 5 ignored**. Пропуски требуют отдельно упакованных
  нативных инструментов или внешнего сервиса и не считаются runtime pass.
- Финальные независимые наборы настоящего React-хука в Edge: **31/31**
  (`cold-upload-playback-independent.mjs`) и **41/41**
  (`soundcloud-playback-independent.mjs`). Проверены запрет VK, включённое и
  выключенное предпочтение SoundCloud, ручная привязка, очередь, shuffle,
  свежие ограничения, отмена и повторное истечение потока.
- Дополнительный набор управляемого повторного запуска при stall: **10/10**.
  Проверены предел повторов, сохранение позиции, общий бюджет отказов и
  истечения ссылки, независимость следующего трека, пауза и переключение.
  Ответы провайдеров и медиачасы в этих трёх наборах подставные.
- Финальная native QA-сборка Tauri с подставной библиотекой VK и реальными IPC,
  SoundCloud/VPS, медиапротоколом и декодером автоматически выбрала ожидаемые
  SoundCloud ID для обоих сообщённых треков и прошла запуск с перемоткой.
  Вместе с тремя ограниченными VK-записями: **5/5 попыток успешно, 75 ответов
  медиа HTTP 200, 0 ошибок renderer**. Звук приглушён.
  Для `все сложно` первые три секунды медиачасов достигнуты за 4932 мс,
  для `МальчикТемныйНачальник` — за 4579 мс; позиция после seek проверена.
- В той же финальной native-сборке прошли три записи с `available=false` VK:
  синтетический `breath` с присутствующей карточкой артиста (4885 мс),
  `KEEP IT REAL` (4445 мс) и `королева селфхарма` (4334 мс).
  Во всех случаях использован независимый SoundCloud-источник; статус
  недоступности VK не был ошибочно переписан.
- Отдельная fault-injection проверка вернула HTTP 503 для первого manifest.
  Встроенный HLS retry восстановил воспроизведение и seek (5931 мс, без VK).
  Строгое ожидание теста о новом вызове SoundCloud resolve не выполнено:
  повтор состоялся внутри HLS. Отчёт сохраняет этот недостаток покрытия как
  `failed`; это не отказ воспроизведения. Новый обработчик приложения проверен
  синтетическими наборами, но в этом native-прогоне не был вызван.

Дополнительно независимые отрицательные проверки настоящего matcher:
**19/19**. Найдены и устранены ложные exact для `mono/radio`, `chopped/pitched`,
`Part II`, `VIP/Dub`, `8D`, `bass boosted` и `без мата` внутри кредитов.

В промежуточной QA-сборке оба сообщённых трека прошли целиком до естественного
`ended`: 156,450929 и 133,897867 секунды, без промежуточных waiting/stalled/error.
Максимальные интервалы `timeupdate` 280/281 мс не измеряют слышимые прерывания.
Повторные breath и blue с перемоткой также прошли: 78 ответов медиа HTTP 200,
ошибок renderer нет. После ужесточения matcher (до изменения повторной попытки)
отдельно прошли три записи с недоступностью VK и три исправленных формата
метаданных: подтверждённое `+имя`, `[все площадки]`, emoji-only название.
Единичный отказ касари в этой серии сохранён в отчёте, успешный отдельный
повтор не отменяет зафиксированного отказа.

Финальный native QA-exe имеет SHA256
`bcb131343d562c5ba476a0d6cbd16d056507a0ffbadb4afcf6265e53e2d9a069`;
matcher в нём имеет SHA256
`14cd11793969ad3067c5a604be4b0f107f3a83409054cb2bbd2bec734fcafee5`.
Промежуточные полные прогоны не подменяют проверку итогового источника:
последняя сборка проверена запуском и перемоткой, а не полным проигрыванием
каждого трека. Все native прогоны выполнялись без вывода звука, поэтому
слышимые микропрерывания физически не измерялись.

Во время финальных повторов VPS кратковременно перестал отвечать на SSH/HTTPS;
причина не установлена и перегрузка не доказана. Позже соединение восстановилось
без перезапуска: публичный `/healthz` вернул HTTP 200 за 266–282 мс, SSH снова
подключался, нагрузка и память были штатными.

## Платформы и сохранность данных

Изменения общие для `src/` и `src-tauri/`. Идентификатор
`ru.vkplayer.desktop`, расположение библиотеки и настроек сохранены.
QA использует другой identifier и временный профиль без пользовательских cookies.

Локальная проверка выполнялась на Windows. Результаты новой сборки macOS
arm64/x64 из релизного тега публикуются в GitHub Actions и описании Release.

preview.4 не проверяет preview.6. Android пока не реализован. Постоянная доступность
произвольной записи внешнего каталога не гарантируется.
