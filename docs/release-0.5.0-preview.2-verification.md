# Pulse 0.5.0-preview.2 — подключение ключей SoundCloud

Дата: 22 октября 2026 года. Локальная Windows preview, без публикации stable.
Общий frontend и Rust backend сохраняют идентификатор `ru.vkplayer.desktop`,
папки профиля и библиотеку. Android не реализован. Изменения предыдущего preview
и его ограничения описаны в [отчёте preview.1](release-0.5.0-preview.1-verification.md).

## Изменения

- Импорт Client ID/Client Secret из выбранного пользователем JSON в системное
  хранилище, без чтения секрета обратно в интерфейс и без встраивания в EXE.
- Ограниченное чтение и проверка структуры, типов и значений; отмена и ошибка
  не изменяют прежние настройки. Отсутствующее поле `proxy` сохраняет маршрут.
- Отдельная команда проверки доступа: OAuth и публичный поиск. Сохранение
  настроек само по себе не называется успешной проверкой API или аудиопотока.
- Запрос refresh token приведён к опубликованному формату SoundCloud;
  первоначальный client credentials продолжает использовать HTTP Basic.
- [Шаблон и инструкция](soundcloud-setup.md) для первичного подключения.

## Проверки

TypeScript, production frontend build, 86 frontend unit-тестов и 284 Node-регрессии
прошли. Новый независимый actual-App сценарий с имитацией IPC: 19 проверок
импорта, отмены, ошибок, одновременных операций, ухода из настроек и очистки
секретов прошли. Прежний сценарий поиска/привязки SoundCloud также прошёл.
Rust offline: 141 прошёл, 5 ignored (кодеки и внешняя сеть). Проверены строгий
JSON, заглушки, BOM, ограничение размера, сохранение маршрута и формат OAuth
запросов. Раскладка настроек просмотрена при ширине 960 пикселей.
При независимой проверке исправлен приём прокси с портом `0`; добавлена
регрессия для HTTP и SOCKS5h. Импорт JSON и проверка API используют общий
код на Windows/macOS, платформенное различие остаётся в системном диалоге
и хранилище ключей. Проверка доступа целиком ограничена 30 секундами.

На свежей изолированной Windows QA-сборке:
- Импорт с 16 неверными файлами, включая оба варианта порта `0`: 9/9 сценариев
  прошли. Файл, настройки и библиотека не изменены; содержимое файла и пути
  не попали в ошибки или логи.
- Отмена выбора: отдельный прогон 9/9 прошёл, команда вернула `null`.
- Проверка доступа без настроек завершается понятной ошибкой быстрее 2 секунд.
- Настоящие IPC и `pulse-media` CORS/CSP проверки прошли в обоих прогонах.
- `node qa/tauri-integration.mjs` прошёл на финальной QA-сборке: импорт
  настоящего WAV, продвижение часов аудио, сохранение позиции/библиотеки
  и явное гостевое состояние VK.

Импорт проверялся через отладочный выбор fixture-файла, разрешённый только для
отдельного QA-идентификатора и изолированного профиля. Выбор реального файла
в системном диалоге и успешная запись выданных ключей в keyring не выполнялись;
формат и преобразование проверены unit-тестами. Пользовательский Pulse и его
профиль не изменялись.

Windows production-сборка `node scripts/tauri.mjs build` завершена успешно.
Установщик `release-tauri/VK Player_0.5.0-preview.2_x64-setup.exe`:
107 704 034 байта (102,71 МиБ), SHA-256
`354bdfc72de56f5e18e04b538e49acc7ab8e772d8297b527f248bbbeb8a31d04`.
ProductVersion/FileVersion исполняемого файла — `0.5.0-preview.2`;
строки отладочных переменных `VK_PLAYER_QA_PROFILE`, `VK_PLAYER_QA_FILES`
и `VK_PLAYER_QA_SOUNDCLOUD_FILE` в production EXE отсутствуют. Система выбора
fixture-файла не включена в поставляемую release-сборку. Установщик не запускался
поверх пользовательского профиля.

Реальные Client ID/Client Secret не предоставлены: проверка SoundCloud с ними,
живой поиск/полный аудиопоток и восстановление проблемных VK-записей пока не
подтверждены. Рабочий зарубежный прокси и новая версия на физическом Mac здесь
не проверены; успешная Windows-сборка этого не устанавливает. Публичный сервер
для хранения общего секрета и управления квотами не развёрнут.
