# Очистка репозитория Pulse — 24 октября 2026

Основная ветка содержит только поддерживаемую Tauri-сборку Windows/macOS.
Версия приложения остаётся 0.5.2; эта очистка не заменяет опубликованные EXE/DMG
и не меняет тег выпуска, профиль, идентификатор или формат библиотеки.

## Что удалено

- Шесть файлов старой оболочки `electron/`, включая main/preload, хранение,
  чтение метаданных и OAuth. Tauri реализует эти возможности в Rust.
- Пять проверок, которые импортировали только Electron-код. Их удаление
  уменьшает Vitest на 2 теста, Node QA на 8; текущие Rust-проверки диапазонов,
  восстановления хранилища и OAuth сохранены.
- Устаревший план перехода на Tauri и сравнительный memory benchmark, который
  запускал старые production-бинарники. Актуальный замер дерева процессов
  `qa/measure-process-tree.ps1` работает только на чтение.
- 45 автоматически созданных Android/iOS/UWP-иконок: эти targets сейчас не
  реализованы. SVG-исходник и все desktop-иконки, включая `icon.png` для
  неявного fallback Tauri, сохранены. При появлении Android ресурсы нужно
  сгенерировать заново и проверить в его платформенном проекте.
- Electron `main`, команды запуска и упаковки, конфигурация electron-builder
  и прямые зависимости `electron`, `electron-builder`, `music-metadata`,
  `concurrently`, `wait-on` из npm manifest/lockfile.

Удалено 58 файлов, 719 219 байт исходников и ресурсов. В npm lockfile осталось
92 package entries вместо 403: удалена 311 запись, включая платформенные optional
пакеты. Это количество записей lockfile, а не одновременно установленных пакетов.
Версии и integrity оставшихся пакетов не изменены; новые зависимости не добавлены.

## Что сохранено

Общий frontend, Rust backend, Pulse Gateway, все активные build scripts,
Tauri/Edge/WebView2 QA, документация и опубликованные релизы. Rust
`legacy_profile()` по-прежнему переносит старую библиотеку без запуска Electron;
удаление старой оболочки не должно отнимать этот переход у пользователей.

Исторические отчёты отражают состояние соответствующих тегов. Старые исходники,
тесты и ресурсы доступны в [теге v0.5.2](https://github.com/XxNellonxX/Pulse---Player-for-VK/tree/v0.5.2).
История Git не переписывалась. Android по-прежнему запланирован, iOS/UWP не
объявлены поддерживаемыми платформами.

## Проверки

- Чистый `npm ci` и полный `npm audit`: прошли, известных npm advisories — 0.
- TypeScript / production frontend build прошли.
- Vitest: 196 прошли; Node regression: 308 прошли.
- Rust: 213 прошли, 6 ignored.
- Windows Tauri debug build с отдельным QA identifier прошёл.
- Нативная Windows QA: **13/13** — настоящие WAV, импорт, воспроизведение,
  перемотка, сохранение очереди и повторный запуск отдельного процесса.
- Чистый Edge: **12/12** переход к текущему треку, **9/9** перемешивание
  подборки, **12/12** управление автозапуском через контролируемый bridge.
- Независимая проверка графа импортов: удалённые Electron-модули не используются
  оставшимися исходниками; build scripts и desktop icon fallbacks сохранены.

Обе macOS-цели, Apple Silicon и Intel, успешно собраны в

импорт, обновление или автозапуск на устройстве. Пользовательский профиль и
установленный плеер в проверках не изменяются.
