# Подключение SoundCloud к Pulse

Для первоначальной проверки своего приложения SoundCloud используйте Pulse
0.5.0-preview.2 или новее. Уже выданные Client ID и Client Secret можно ввести
прямо в «Настройки → Источники музыки» или импортировать из JSON-файла.
Обычная авторизация на сайте SoundCloud не заменяет эти данные.

## Подключение из файла

1. Откройте `soundcloud-credentials.json` в Блокноте или другом текстовом редакторе.
2. Замените `PASTE_CLIENT_ID_HERE` своим Client ID, а `PASTE_CLIENT_SECRET_HERE`
   своим Client Secret. Сохраните двойные кавычки, запятую и фигурные скобки.
3. В Pulse откройте «Настройки → Источники музыки → Импортировать файл ключей»
   и выберите сохранённый JSON. Его не нужно переносить в папку установки.
4. Нажмите «Проверить доступ». Успешная проверка подтверждает получение токена
   и работу публичного поиска, но не доступность каждой аудиозаписи.
5. Оставьте включённым «Предпочитать SoundCloud» для автоматического подбора
   источника по данным записи. Неоднозначное совпадение требует выбора версии.

Файл выглядит так, но вместо заглушек должны быть ваши значения:

```json
{
  "clientId": "PASTE_CLIENT_ID_HERE",
  "clientSecret": "PASTE_CLIENT_SECRET_HERE"
}
```

Ключи импортируются в Windows Credential Manager или macOS Keychain. Сам файл
остаётся обычным текстом: после успешного импорта его можно удалить. Не
публикуйте заполненный файл, скриншот ключей или Client Secret в чате/GitHub.
Секреты не встраиваются в установщик и не возвращаются в интерфейс из файла.

Отмена выбора и неверный JSON не заменяют прежние настройки. Необязательное
поле `proxy` меняет только маршрут SoundCloud; без него прежний маршрут
сохраняется. Прокси также можно настроить отдельно в интерфейсе. Пустое значение
`proxy` явно включает прямое соединение в личном режиме.

## Публичная версия

Эта инструкция предназначена для личного режима владельца приложения.
Начиная с preview.4 в обычной сборке включён общий HTTPS-сервис Pulse:
ключи находятся на сервере, слушателю не нужно их вводить. Личные ключи остаются
в системном защищённом хранилище и не используются скрыто при сбое общего сервиса.
Доступны [комплект для VPS](../services/pulse-gateway/README.md)
и [состояние публичной сборки](pulse-service-setup.md). Личные ключи не следует
добавлять в публичную desktop-сборку.

Для новой регистрации SoundCloud сейчас требует Artist Pro:
https://developers.soundcloud.com/docs/api/register-app.
API предоставляет разрешённые потоки, а не универсальный доступ ко всем
записям и не разрешение перезаливать SoundCloud-аудио в VK. Проверяйте текущие
лимиты: https://developers.soundcloud.com/docs/api/rate-limits.
