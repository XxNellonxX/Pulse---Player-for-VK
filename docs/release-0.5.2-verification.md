# Pulse 0.5.2 — проверка обновления

24 октября 2026 года. Windows и macOS используют общий frontend и Rust backend,
версия 0.5.2 и идентификатор `ru.vkplayer.desktop`. Миграция очереди добавляет
необязательный `queueSource`, совместимый с прежними профилями; расположения
данных не меняются. Android пока не реализован.

## Исправления и независимые проверки

- Перемешивание ограничено активной подборкой. Проверка настоящего App и hook
  в чистом Edge: **9/9**. Проверены другой альбом, несколько циклов repeat-all,
  исходный порядок после отключения, редактирование очереди, перезапуск,
  одиночная запись и результат поиска вне собственной библиотеки.
- Плавное раскрытие текущего трека: **12/12** в чистом Edge. Проверены более
  120 строк в App и 30 у артиста, продолжение после раскрытия страницы,
  focus/visibility, ручная прокрутка, другой альбом, повторы, диалоги и
  reduced motion. События возврата окна моделировались; физический Alt+Tab
  в установленном пользовательском плеере этим прогоном не проверялся.
- Новый native IPC guard проверен в отдельном `VK Player QA`, со своим профилем:
  **13/13**. Настоящие WAV, импорт коллекции, порядок, mute, ход времени,
  перемотка, очистка неизвестных секретных полей и перезапуск прошли. Исходный
  порядок и активная очередь сохранились после настоящего перезапуска процесса;
  команды автозапуска доступны через IPC, но QA не может менять системные записи.
  Основной установленный плеер и его профиль не изменялись.
- Gateway: **78/78**, без пропусков, включая настоящий локальный Caddy,
  контролируемый HTTP upstream, HLS/seek и ограничения ресурсов.
- TypeScript прошёл; Vitest **198/198**; Node regression **316/316**;
  Rust на Windows **213 прошли, 6 ignored**, включая 6 проверок автозапуска.

## Автозапуск и платформы

Автозапуск реализован общим интерфейсом и отдельными системными адаптерами:
Windows HKCU Run / StartupApproved и macOS SMAppService. Однократное включение
использует предварительно сохранённый маркер; последующее отключение не отменяется.
Независимый чистый Edge: **12/12** UX-сценариев — подтверждение системного состояния,
ошибки, повторные клики, конкурирующие чтения и разрешение macOS. В QA/dev
системная регистрация отключена; производственная перезагрузка Windows не выполнялась.
После полного удаления Windows-приложения запись Run пока может остаться;
перед удалением её следует отключить в Pulse или настройках Windows.
Статус платформенных пакетов и публикации будет записан после сборки.
Отсутствие физического Mac не позволяет подтвердить вход, Keychain, импорты,
воспроизведение, обновление или системный запуск на этом устройстве.
Неподписанные Mac-пакеты остаются preview даже при успешной компиляции.

## Безопасность и пределы

Подробные изменения, исправленные и оставшиеся advisories:
[отчёт безопасности](security-hardening-2026-10-24.md).
Локальный аудит исходников и тесты не гарантируют отсутствие всех уязвимостей.
Поведение реальных внешних сервисов и физический аудиовыход не заменяются
fixture-проверками.

Gateway обновлён на действующем VPS с приватной резервной копией и подготовленным
откатом; окружение с ключами и TLS volumes сохранены. В контейнере кандидата
**37/37** тестов без сети, Caddy validate прошёл; HTTPS health 200 и gateway healthy
подтверждены после замены. Две штатные проверки SoundCloud получили manifest
и первый ресурс, но не проигрывали целую песню. MusicBrainz в этом проходе
вернул HTTP 502; доступность всех провайдеров не подтверждена.

## Пакеты

Windows EXE и Apple Silicon / Intel DMG должны быть собраны из одной ревизии
и опубликованы в одном выпуске. Ревизия, CI и контрольные суммы будут добавлены
по фактическому завершению сборки; более ранние результаты 0.5.1 не засчитываются.
