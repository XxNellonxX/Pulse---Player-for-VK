## История: проверенная сборка 0.4.1

Версия 0.4.1 для macOS 14 и новее успешно собрана для Apple Silicon (arm64) и Intel (x64) в [GitHub Actions](https://github.com/XxNellonxX/Pulse---Player-for-VK/actions/runs/39638095778). DMG и контрольные суммы опубликованы как [macOS preview 0.4.1](https://github.com/XxNellonxX/Pulse---Player-for-VK/releases/tag/v0.4.1-macos-preview). Сборка и тег preview закреплены на `bc5cda814c6fad420a3e7a990b5d4ed9f59b70bf`; production-код (`src/`, `src-tauri/`, `scripts/`, `package.json` и `package-lock.json`) идентичен `c2a671b8be05faa66f51de95721480c603a453bd`, из которого выпущена версия Windows 0.4.1. Обе архитектуры прошли TypeScript, Vitest, Node regression suite и сборку Tauri; [перенос проверенных артефактов](https://github.com/XxNellonxX/Pulse---Player-for-VK/actions/runs/39640727685) завершён успешно.

Проверка входа и аудио на физическом Mac ещё не выполнена, поэтому это предварительная версия без подписи и notarization Apple. На Mac используется WKWebView. Профиль VK хранится в постоянном идентификаторе `WKWebsiteDataStore`, чтобы обновление приложения сохраняло вход; при явном выходе идентификатор меняется и старая сессия больше не подхватывается.

Предыдущая [macOS preview 0.4.0](https://github.com/XxNellonxX/Pulse---Player-for-VK/releases/tag/v0.4.0-macos-preview) собрана в [запуске 39628697180](https://github.com/XxNellonxX/Pulse---Player-for-VK/actions/runs/39628697180) и сохранена в истории релизов.

Сборка выполняется на macOS, а не на Windows:

```bash
npm ci
npm run typecheck
npm test
npm run dist:mac
```

Команда загружает только закреплённые по SHA-256 компоненты импорта и создаёт `.app` и `.dmg`. macOS Gatekeeper может запросить разрешение для неподписанной сборки. Инструменты аудио запускаются только во время импорта и подготовки файлов. Для полностью проверенного стабильного Mac-релиза необходимы физические runtime-проверки, подпись и notarization сертификатом Apple. Стабильный Windows-выпуск может содержать отдельно помеченные экспериментальные Mac-пакеты той же версии. Workflow собирает неподписанные проверочные DMG, без секретов Apple, и сохраняет их в артефактах GitHub Actions. Версия 0.4.1 доступна отдельно как prerelease; автоматической публикации проверочных сборок в стабильный канал нет. На момент публикации preview 0.4.1 API `releases/latest` продолжал возвращать стабильный релиз Windows `v0.4.1`; это историческое наблюдение, а не текущее состояние канала.

Для обновления завершите Pulse, откройте новый DMG и замените приложение в папке «Программы». Идентификатор `ru.vkplayer.desktop` и расположение данных остаются прежними. Перед стабильным релизом на физическом Mac необходимо проверить запуск старого профиля, сохранение `library.json`, восстановление cookie-профиля VK и удаление временной папки импорта. Эти сценарии на Mac пока не подтверждены.

## Импорт ссылок

Прямые публичные аудиофайлы и разрешённые оригиналы SoundCloud сохраняются без дополнительного перекодирования. YouTube использует `yt-dlp` и `ffmpeg`; исходный поток сохраняется локально, а при загрузке в VK создаётся MP3 320 кбит/с, потому что VK принимает этот формат.

Ссылки Яндекс Музыки передаются распознанному экстрактору; импорт возможен, только когда сервис отдаёт полный доступный поток без DRM. Spotify не предоставляет поддерживаемый способ получить полный файл по публичной ссылке, поэтому его треки не скачиваются. Pulse не заменяет исходный трек результатом поиска VK. Защищённые потоки, платная подписка или вход на стороннем сайте не обходятся, а превью не должны добавляться как полная песня.

Если сайт не даёт доступный полный файл, Pulse сообщает это в результате импорта и оставляет библиотеку без частичного трека. Прямые ссылки и обычные страницы с опубликованным `audio src` или `og:audio` обрабатывает HTTP-загрузчик с проверкой публичного HTTPS-адреса на каждом редиректе. Известные медиа-сайты использует отдельный экстрактор; все загрузки ограничены размером и временем, временные файлы удаляются после завершения.
