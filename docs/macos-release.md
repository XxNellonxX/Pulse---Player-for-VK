# macOS сборка Pulse

В проекте подготовлена сборка для macOS 14 и новее в двух вариантах: Apple Silicon (arm64) и Intel (x64). До успешного запуска CI и проверки на настоящем Mac она не считается готовым релизом. На Mac используется WKWebView. Профиль VK хранится в постоянном идентификаторе `WKWebsiteDataStore`, чтобы обновление приложения сохраняло вход; при явном выходе идентификатор меняется и старая сессия больше не подхватывается.

Сборка выполняется на macOS, а не на Windows:

```bash
npm ci
npm run typecheck
npm test
npm run dist:mac
```

Команда загружает только закреплённые по SHA-256 компоненты импорта URL и создаёт `.app` и `.dmg`. macOS Gatekeeper может запросить разрешение для неподписанной сборки; приложение не запускает бинарники импорта без действия пользователя «Добавить по ссылке». Перед публикацией maintainer должен настроить подпись и notarization сертификатом Apple. Пока workflow собирает неподписанные проверочные DMG, без секретов Apple, и сохраняет их только в артефактах GitHub Actions. Автоматической публикации непроверенной macOS-сборки в Releases нет.

Обновление ставится поверх предыдущего `.dmg`: идентификатор `ru.vkplayer.desktop` и папка данных остаются прежними. Перед релизом проверяются запуск старого профиля, сохранение `library.json`, восстановление cookie-профиля VK и удаление временной папки импорта. Неподписанный локальный DMG нельзя считать готовым релизом.

## Импорт ссылок

Прямые публичные аудиофайлы и разрешённые оригиналы SoundCloud сохраняются без дополнительного перекодирования. YouTube использует `yt-dlp` и `ffmpeg`; исходный поток сохраняется локально, а при загрузке в VK создаётся MP3 320 кбит/с, потому что VK принимает этот формат.

Ссылки Яндекс Музыки передаются распознанному экстрактору; импорт возможен, только когда сервис отдаёт полный доступный поток без DRM. Spotify не предоставляет поддерживаемый способ получить полный файл по публичной ссылке, поэтому его треки не скачиваются. Pulse не заменяет исходный трек результатом поиска VK. Защищённые потоки, платная подписка или вход на стороннем сайте не обходятся, а превью не должны добавляться как полная песня.

Если сайт не даёт доступный полный файл, Pulse сообщает это в результате импорта и оставляет библиотеку без частичного трека. Прямые ссылки и обычные страницы с опубликованным `audio src` или `og:audio` обрабатывает HTTP-загрузчик с проверкой публичного HTTPS-адреса на каждом редиректе. Известные медиа-сайты использует отдельный экстрактор; все загрузки ограничены размером и временем, временные файлы удаляются после завершения.
